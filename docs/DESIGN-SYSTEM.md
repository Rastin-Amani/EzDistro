# EzDistro Signal

EzDistro’s interface is a quiet workspace for SEO research, indexing, writing, and publishing. It borrows the clarity of an engineering blueprint: white space, precise type, fine rules, and one confident action color. Color and motion communicate state; neither is decoration.

## Foundations

| Role | Value | Use |
| --- | --- | --- |
| Paper | `#ffffff` | Main canvas and elevated surfaces |
| Mist | `#fafafa`, `#f5f5f5` | Quiet surface contrast |
| Rule | `#e8e8e8` | Dividers, outlines, table structure |
| Ink | `#181925` | Primary text, active navigation chips, and dark theme base |
| Lavender | `#918df6` | Primary actions and live pipeline signals |
| Iris | `#9580ff` | Secondary emphasis |
| Mint | `#33c758` | Positive accents and successful progress |
| Muted | `#666666`, `#999999` | Supporting labels and metadata |

Info, warning, and error colors are reserved for their semantic states. The light theme is the first-visit default; a cool dark companion remains available as an explicit preference.

## Type and layout

- Inter is the English interface face; Arad is used for Persian. Locale controls document direction independently of the project’s generated-content language.
- Use a 4px spacing rhythm, generous page breathing room, and a content width capped near 1200px.
- Cards use a 16px radius, fields 8px, and buttons, tabs, and status chips pill shapes. Prefer hairline borders and surface contrast over shadows.
- Keep data readable at a glance with tabular numerals, clear labels, concise headings, and restrained use of accent color.

## Components and behavior

- Shared page headings, panels, metrics, empty states, navigation, forms, tables, and status badges use the same palette and border-first treatment. Active navigation reads as an Ink chip with a lavender icon; lavender stays reserved for actions and live signals.
- The dashboard’s content pipeline rail is the signature composition: four stages on one assembly line, extrabold counts, and a single reduced-motion-aware pulse on the stage that is currently writing.
- Desktop uses a quiet sidebar. Mobile prioritizes a safe-area-aware header, thumb-sized controls, horizontally scrollable project tabs, and a persistent floating pill dock.
- Touch actions stay visible without hover. Every interactive control has a visible keyboard focus ring, sufficient target size, semantic state, and reduced-motion respect.
- English is the default interface language. Persian remains available with RTL layout and locale-aware typography; project content language remains a separate setting.
